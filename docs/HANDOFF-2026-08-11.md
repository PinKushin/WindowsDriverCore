## What was wrong with the apparatus

Two pieces of scaffolding added on 2026-08-10 in one commit (`c62ebde`) to
stabilise the score:

```
reset + warm        281            the two roughly cancelled
reset, no warm      259/259/260    21 ActionsError failures
no reset, no warm   280             0 ActionsError failures
```

- The **reset** moves the app's `Settings` folder away, forcing a genuine cold
  start. A cold activation returns an **intermediate process id**, so both drivers
  hunt for a window owned by a process that does not own it.
- The **warm** step hid that damage. The pair cancelled, so both survived a day.
- The reset was originally a workaround for alarms not deleting. That defect was
  fixed; nobody removed the workaround.

Caught in our own transcript: activation returned **pid 3024** while Alarms ran as
**4852** and was on screen the whole time; a second activation one second later
returned 4852 in 790 ms.

**Three careful runs agreed on 259 and all three were wrong**, because they shared
the confound. Reproducibility is not validity when what is reproduced is the
confound.

## Decisions made

1. **Serve both protocols.** JWP stays the floor and the scoreboard; W3C is
   additive. Selenium 4 dropped JWP, and that is the largest cluster in
   WinAppDriver's tracker (~42 reactions). See `docs/DUAL-PROTOCOL.md`.
2. **The dialect seam goes in before pointer input**, because retrofitting means
   editing every route — the drift that produced WinAppDriver's issue #1079.
3. **Pointer input is built W3C-first**: `/actions` is where W3C put every input
   primitive, and JWP `/touch/*` and `/moveto` become thin wrappers over one input
   path.
4. **No W3C work may cost a JWP test.** The suite runs before and after each step.

## Order of work

1. **Dialect seam** — session creation (`desiredCapabilities` vs `capabilities`),
   envelope, element key, W3C rendering of `WebDriverFault`. Small: one filter
   plus session creation.
2. **Pointer input**, W3C `/actions` first — the measured 30 tests.
3. **Implicit wait** — the ~80 `no such element` finds. Arguably should come
   first; it is the single largest lever and is already on the not-implemented
   list as "the defect that cost the old implementation 167 tests".
4. Moved routes (`/element/{id}/rect`, `/window/handles`, `/execute/sync`) as
   demand appears.

## The instrument

- **Offline by construction.** Adapter disconnected, no switch, Store
  auto-update disabled by policy. `New-BaselineVm.ps1` defaults to no network and
  `Initialize-OfflineGuest.ps1` refuses to run against a connected adapter.
- **Static 4 GB**, so host pressure cannot reach into the guest.
- **Checkpoint** `pristine-alarms-10.1906.2182.0`, taken before anything touched
  it. It is what makes the drifted-app re-measurement reversible.
- **Agent autostarts** from the Startup folder in session 1. It **queues** jobs
  (oldest first) — the lock that refuses rather than queues is the Oracle
  measurement box, a different machine.
- **History preserved** at `F:\Hyper-V\guest-history\` — 38 TRX including the
  pre-drift 281.
- Payload staged at `F:\Hyper-V\offline-payload\`, versions pinned to what every
  prior score used.

## Method lessons worth more than the numbers

- **A wait that spends its whole budget never detected the thing.** Nothing this
  suite drives legitimately takes ten seconds.
- **Reproducibility is not validity.** Three runs, varied load and memory, same
  wrong answer.
- **A workaround outlives the bug it was for.** Record the defect beside the
  workaround, or fixing one will not prompt removing the other.
- **Ask the reference driver first.** Ten minutes settles what an hour of
  reasoning will not.
- **`settings.dat` size is not an alarm count** — a hive allocates in blocks and
  never shrinks. Measuring a proxy that is not faithful to the variable is the
  wrong-instrument failure.
- **A test whose failure destroys the machine is not a test.** The shell check
  asserts the decision, never the action.
- **Make a mutation compile**, or a build failure masquerades as an uncaught
  mutation.
- **Request counts are not test counts.**
